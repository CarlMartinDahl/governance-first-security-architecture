# Project Identity

## Official Name

The official public project name is:

```text
Governance-First Security Architecture Project
```

Short reference:

```text
GFSA Project
```

The established document-series title remains:

```text
Governance-First Security Architecture
```

## Current Classification

The project is a documentation-only architecture project frozen for external review.

It is not currently:

- a software platform,
- a security platform,
- a product,
- a security agent,
- an implementation,
- a validated standard,
- a certification or compliance scheme.

An independent implementation may accurately say that it is based on or informed by the Governance-First Security Architecture Project when the attribution and no-endorsement requirements are followed.

## Canonical And Independent Work

The repository at `https://github.com/CarlMartinDahl/governance-first-security-architecture` is the canonical project source.

Independent forks and derivatives should use names that distinguish them from the canonical project. They may use the official name descriptively to identify origin, for example:

```text
Based on the Governance-First Security Architecture Project by Martin Dahl.
```

They should not use the project name, visual identity, or release language in a way that implies that an independent work is official, endorsed, validated, certified, or maintained by Martin Dahl.

## Identity Rights

CC BY-SA 4.0 licenses applicable copyright and similar rights in the original documentation. It does not grant trademark rights or a right to imply endorsement.

No registered-trademark status is claimed in this repository. This identity policy records project-origin and no-confusion expectations; it does not prevent accurate descriptive attribution or other use permitted by law.

No logo is currently designated as an official project mark.

## Future Platform Language

The word `platform` should be used for this project only after an actual technical platform exists and a later governance decision explicitly authorizes that description.
